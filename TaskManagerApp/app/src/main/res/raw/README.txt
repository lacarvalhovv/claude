# Sound Files

Place the following OGG audio files in this directory:
- sound_beep.ogg   - Short beep sound
- sound_chime.ogg  - Chime sound  
- sound_bell.ogg   - Bell sound
- sound_urgent.ogg - Urgent alarm sound

If files are missing, the app falls back to the system default notification sound.
You can use free sounds from freesound.org or generate them with tools like Audacity.
